## Goal

Move the harbour simulator from a playable technical prototype to a low-speed manoeuvring core in which the player must anticipate inertia, residual motion and the delayed effect of bridge commands.

The renderer remains non-authoritative. Campaign settlement remains outside the simulation core. Existing 2D harbour behaviour remains the production fallback until P5.3 human usability is accepted.

## P5.3-D — Vessel & Load Calibration

**Branch:** `feat/p5.3d-vessel-calibration`  
**PR:** #17 — merged

### Scope

Handysize is the low-speed reference. Other vessel classes are calibrated relative to that reference:

- Coaster: agile, short response and stopping distance
- Handysize: reference low-speed handling
- Feeder: higher windage and lateral sensitivity
- Panamax: high inertia, long stopping distance and slow yaw response

Load state measurably affects acceleration, stopping and turn response.

### Gate

- AT-07 class distinction
- AT-08 load distinction
- normalized Panamax stopping distance >= 1.8 × Coaster
- benchmark evidence recorded in `docs/p5.3-calibration-evidence.md`

**Result:** complete.

## Final P5.3 integration gate

P5.3 may merge to `main` only when:

1. ✅ all ten automated acceptance gates AT-01…AT-10 are green;
2. ✅ CI and production build are green;
3. ⏳ Handysize low-speed response is accepted by human play test;
4. ✅ Alongside Berthing, Unberthing and Turning Basin are implemented and automated goal logic is green;
5. ✅ P6 campaign integration and persistence tests remain intact;
6. ✅ the legacy 2D harbour path remains in place as fallback;
7. ⏳ physical-phone usability is accepted in portrait and landscape.

The remaining work is therefore **human acceptance, not further implementation**. Use `docs/p5.3-human-acceptance.md` as the binding protocol.

The final product question is:

> Does the player have to think ahead about the ship's future motion?

If late corrective inputs can still make a large ship stop, rotate and berth almost immediately, P5.3 is not complete and the failed human criterion must become a focused follow-up slice.
